# Taskly UI

A small React + Vite task board. It is the base branch for Kiro IDE demos.

## Run

```bash
npm install
npm run dev      # http://localhost:5173
npm run build
```

Requires Node.js 18 or later.

## Structure

- `src/App.jsx` loads tasks and renders the board.
- `src/components/` holds Header, AddTaskForm, TaskColumn and TaskCard.
- `src/styles.css` holds all styling.
- `public/tasks.json` is the sample data.
